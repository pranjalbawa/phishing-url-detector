How it works

The model extracts ~26 lexical and structural features directly from the URL text — length, special-character counts, domain entropy, suspicious keywords, IP-literal hosts, URL shorteners, and more — then a Random Forest classifier estimates the probability that the URL is a phishing attempt. No page content is fetched, so results are instant and safe to run on untrusted links.
